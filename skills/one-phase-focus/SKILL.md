# Одна фаза до конца

Не сворачивать с активной части, пока она не закрыта. Парковка и бэклог — позже.

## Источник правды

В корне проекта (или рядом с кодом) файл **`FOCUS.md`** (или аналог):

- **Сейчас** — одна активная фаза + одна задача
- **Чеклист** фазы — `[ ]` / `[x]`
- **Парковка** — идеи «потом», не трогать
- **Бэклог** — фичи вне текущей фазы

Если `FOCUS.md` нет — предложи создать минимальный, не начинай расползание.

## В каждом ответе

Первой строкой (или сразу под статусом чата):

`Сейчас: [фаза] — [задача]`

как в `FOCUS.md`.

## Одна активная задача

- Пока фаза не закрыта чеклистом — **не** кодить новые фичи из парковки/бэклога.
- Увод в сторону («пока красиво», новый экран, редизайн HUD, «заодно LLM», соседний модуль) → коротко отказать, предложить запись в парковку `FOCUS.md`, вернуть к активной задаче.
- Следующую фазу начинать только после явного **«готово / протестировал / дальше»** от пользователя **или** полностью зелёного чеклиста активной фазы.

## Разрешено без смены фазы

- Багфикс активной фазы
- Крошечный UX / правка, без которой нельзя пройти тест текущей фазы
- Документация чеклиста (`FOCUS.md`), если отражает уже сделанное

## Парковка

Новые идеи записывать в секцию «Парковка» / «Бэклог» `FOCUS.md`, **не** реализовывать «заодно».

## Антипаттерны

| Не делать | Делать |
|-----------|--------|
| «Пока чиню X, добавлю ещё Y из бэклога» | Только X (или багфикс X) |
| Начать P6, пока P5 не зелёный | Дожать чеклист P5 |
| Молча сменить активную фазу | Спросить / ждать «дальше» |
| Красивый рефакторинг соседней системы | Запись в парковку |

## Шаблон отказа

> Сейчас активна **[фаза]**. Это из парковки/бэклога — запишу в `FOCUS.md`, вернёмся после закрытия чеклиста. Продолжаем: **[текущая задача]**.
